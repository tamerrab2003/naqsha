# Naqsha 0.9.6: fixes for right-to-left, the browser and template links

A small release on top of [0.9.5](https://github.com/tamerrab2003/naqsha/releases/tag/v0.9.5).

## Fixes
- **Arabic, Persian and Urdu:** the Home ribbon now lays out right to left properly. Before, the shape style swatches were cut off and the Arrange and Editing groups were hidden.
- **Browser version:** the language menu shows 简体中文, 繁體中文 and 日本語 instead of empty boxes. The Chinese and Japanese font now loads when you open the menu.
- **Template links:** `nixpx.com/naqsha/app?template=pro:pump_station` (or any Pro template) opens that template. Without Pro or the trial, the Pro dialog opens first, as in the template gallery.

## ONLYOFFICE
- The Naqsha plugin is now in the ONLYOFFICE marketplace: install it from **Plugins › Plugin Manager**.

## Builds
- The macOS disk image is built with an explicit size and retried if the build machine's `hdiutil` fails.
